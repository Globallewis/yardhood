# Yardhood

Code for yardhood.com (WordPress + BuddyBoss).

- `theme-yardhood/` : the Yardhood child theme (parent: BuddyBoss Theme). Installs to `wp-content/themes/yardhood`.
- `plugin-yardhood-core/` : Yardhood Core plugin (Yard Guide events + RSVP, Stories, Submit Your Story, hosting, widgets, setup tools). Installs to `wp-content/plugins/yardhood-core`.

BuddyBoss Platform, Platform Pro and BuddyBoss Theme are licensed products and are not stored here.
No passwords, API keys or Stripe keys belong in this repository.
